# 📸 Apna College — Photography Website-------------

A responsive photography/museum-style website built with **HTML & CSS**, featuring a sleek dark-themed sidebar navigation and a full-screen hero image layout.

---

## 🖼️ Preview------

> Dark sidebar layout with a full-screen DSLR camera hero image and social media links.

---

## 🚀 Features----

- **Sidebar Navigation** — Fixed left-side nav with icon + label menu items
- **Full-Screen Hero Image** — Cinematic dark background with a DSLR camera photograph
- **Dark Theme** — Deep charcoal/black color palette for a professional, moody aesthetic
- **Social Media Links** — Footer icons for Facebook, Twitter, Instagram, and YouTube
- **Clean Typography** — Light-weight white text on dark background for readability

---

## 📌 Key CSS Concepts Used

- `flexbox` — for sidebar and content layout
- `position: fixed` — for sticky sidebar
- `background-image` + `object-fit` — for full-screen hero image
- CSS custom properties (`--variables`) for theming
- Icon integration via image tags or icon fonts
